# B站搜索修复（Bilibili Search Filter）

一个油猴脚本，自动删除 B站搜索结果中与当前搜索关键词无关的视频、影视和广告卡片，让搜索结果更干净。

## 简介

在 B站搜索时，结果里经常混入大量不相关的视频、广告和无关影视卡片。本脚本会根据当前搜索关键词，自动过滤掉标题中不包含关键词的卡片，只保留相关内容。

支持**按空格分词**：搜索“老友记 美剧”时，标题中包含“老友记”**或**“美剧”的项都会保留。

## 功能特性

- 自动读取当前搜索关键词（从 URL 或搜索框）
- 按空格分词，标题命中任意一个分词即保留
- 同时过滤视频卡片、影视/番剧卡片、广告卡片
- 支持动态加载内容（无限滚动、SPA 路由切换）
- 忽略大小写，适配中英文搜索词
- 可在脚本头部开关各项过滤功能
